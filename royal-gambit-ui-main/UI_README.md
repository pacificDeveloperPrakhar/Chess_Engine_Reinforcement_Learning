# Royal Gambit UI

Create an interactive Chess UI component using Next.js (App Router), Tailwind CSS, Framer Motion, and GSAP/Anime.js. The interface needs to handle dynamic board state and legal move overlays sent via gRPC-Web from a custom Rust backend.

---

### Core Requirements & Specifications

#### 1. Technical Stack

- **Framework:** Next.js (TypeScript) + React 18+

- **Styling:** Tailwind CSS

- **Animations:** 

  - Framer Motion for smooth piece movement and board state transitions (`layoutId` or coordinate interpolation).

  - GSAP / Anime.js for piece capturing effects, check highlights, or drop/place bounce animations.

- **Piece Rendering:** SVG icons for chess pieces (White: `P, N, B, R, Q, K`, Black: `p, n, b, r, q, k`).

---

#### 2. Backend Data Formats & Protocols

The server communicates using gRPC-Web streams/messages. Board states are delivered as FEN-like strings formatted through specific Rust logic.

##### Data Type A: Standard Board State String

Generated by `get_pgn_notation_from_bitboards`:

- **Format:** RLE string structured like FEN without additional fields (e.g., `rnbqkbnr/pppppppp/8/8/8/8/PPPPPPPP/RNBQKBNR`).

- **Uppercase:** White pieces (`P`, `N`, `B`, `R`, `Q`, `K`).

- **Lowercase:** Black pieces (`p`, `n`, `b`, `r`, `q`, `k`).

- **Numbers (1–8):** Consecutive empty squares.

- **Slashes (`/`):** Rank separators starting from rank 8 (top-left, square `a8`) down to rank 1 (bottom-right, square `h1`).

##### Data Type B: Legal Move Overlay String

Generated by `get_legal_possible_moves_notation_for_rendering`:

- Superimposes legal move indicators directly onto the current board string:

  - `+`: Valid non-capture destination square.

  - `-`: Valid capture destination square (lands on an enemy piece).

---

#### 3. Client-Side Data Parsing Logic

Write a dedicated parser utility `lib/chessNotationParser.ts` to convert these backend strings into structured board grids:

```typescript

export interface BoardSquare {

  squareIndex: number; // 0 to 63 (0 = a8, 63 = h1)

  file: string;        // 'a' - 'h'

  rank: number;        // 1 - 8

  piece: string | null; // 'P', 'p', 'N', etc. or null

  isMoveDestination: boolean; // true if '+'

  isCaptureDestination: boolean; // true if '-'

}

export function parseCustomFen(fenString: string): BoardSquare[] {

  const squares: BoardSquare[] = [];

  const rows = fenString.split('/');

  

  let globalIdx = 0;

  for (let r = 0; r < 8; r++) {

    const rowStr = rows[r];

    const rank = 8 - r;

    

    let fileIdx = 0;

    for (let c = 0; c < rowStr.length; c++) {

      const char = rowStr[c];

      

      if (char >= '1' && char <= '8') {

        const emptyCount = parseInt(char, 10);

        for (let i = 0; i < emptyCount; i++) {

          const file = String.fromCharCode('a'.charCodeAt(0) + fileIdx);

          squares.push({

            squareIndex: globalIdx++,

            file,

            rank,

            piece: null,

            isMoveDestination: false,

            isCaptureDestination: false,

          });

          fileIdx++;

        }

      } else {

        const file = String.fromCharCode('a'.charCodeAt(0) + fileIdx);

        const isMove = char === '+';

        const isCapture = char === '-';

        

        squares.push({

          squareIndex: globalIdx++,

          file,

          rank,

          piece: isMove || isCapture ? null : char,

          isMoveDestination: isMove,

          isCaptureDestination: isCapture,

        });

        fileIdx++;

      }

    }

  }

  return squares;

}
